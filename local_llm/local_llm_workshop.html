Block 1

Grund für lokales Modell: Datenschutz / Sicherheit

  • Datenschutzbestimmungen bei der Arbeit
  • Persönliche Daten & Vertrauliche Informationen
  • Bestimmungen der lizenzierten E-Ressourcen

Block 1

Grund für lokales Modell: Offline-Nutzung

  • Keine Internetverbindung nötig
  • Keine Abhängigkeit von externen Servern
  • Unabhängigkeit, Stabilität, Verfügbarkeit und Nachhaltigkeit

Block 1

Grund für lokales Modell: Kontrolle über Modell und Daten

  • Modelle selber fine-tunen und anpassen
  • Keine ungewollte Datenweitergabe
  • Transparenz und Nachvollziehbarkeit der Ergebnisse

Block 2

Quantisierung?

"Quantization is a technique to reduce the computational and memory costs of running inference by representing the weights and activations with low-precision data types like 8-bit integer (int8) instead of the usual 32-bit floating point (float32)."

Definition in Hugging Face Documentation

Block 2

Quantisierungsstufen

Muster: Q{Bits}_{Variante}

Beispiel: "Q4_K_M"

  • "4" steht für 4-bit Quantisierung
  • "K" ist für K-Quants (gemischte Präzision)
  • "M" für Medium — ein Gleichgewicht zwischen Modellgröße, Geschwindigkeit und Qualitätsverlust

Block 2

Formate der Modelle

Die folgenden Modellformate können "out-of-the-box" in Ollama installiert werden. Andere Formate können durch Konvertierung verwendet werden.

  • GGUF (GPT-Generated Unified Format)

Block 3 - Hands-on in CLI

Tipps


        $ ollama run [model name] "[Dein Prompt]" > example.txt # Antwort in Textdatei speichern
        $ ollama show [model name] # Modellinformationen anzeigen

Wenn man die Einstellung eines Modells ändern möchte, kann man im Chat mit dem entsprechenden Modell folgende Befehle eingeben.


        # Im Chat mit dem Modell:
        /set parameter temperature 0.7 # Temperatur einstellen
        /set parameter num_ctx 32768 # Maximale Tokenanzahl einstellen
        /save [model name] # Modell mit der neuen Konfiguration speichern
